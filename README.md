# Courier Local

Sistema de gestión y optimización de entregas de última milla para mensajería y paquetería local (San Pedro de Macorís y zonas aledañas).

## 📁 Estructura del Proyecto

- **`base-de-datos/`**:
  - `schema.sql`: Definición del esquema de base de datos relacional para PostgreSQL / Supabase.
  - `datos-iniciales.sql`: Datos semilla e iniciales para configuración de zonas y parámetros operativos.
- **`propuesta/`**:
  - `anteproyecto.html`: Documento de propuesta técnica y funcional en formato interactivo/web.
  - `Courier-Local-Anteproyecto.pdf`: Documento formal del anteproyecto del sistema.

## 🚀 Puesta en Marcha (Base de Datos)

1. Crear un proyecto en [Supabase](https://supabase.com/) o una base de datos PostgreSQL.
2. Ejecutar `base-de-datos/schema.sql` en el editor SQL.
3. Cargar los datos iniciales con `base-de-datos/datos-iniciales.sql`.
